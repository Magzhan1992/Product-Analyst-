Project Analyst One — выявить группы гильдий с различным уровнем активности и исследовать связь между активностью гильдий и платежным поведением их создателей.

Основная задача данного проекта:

1.Загрузить данные о гильдиях, игровой энергии и платежах.

2.Отобрать гильдии, созданные в ноябре и декабре 2022 года.

3.Объединить информацию о гильдиях и накопленной игровой энергии.

4.Подготовить количественные признаки активности.

5.Обработать пропущенные и некорректные значения.

6.Стандартизировать показатели для последующей кластеризации.

7.Определить подходящее количество кластеров.

8.Сегментировать гильдии с помощью алгоритма K-Means.

9.Охарактеризовать кластеры и разделить их на группы низкой, средней и высокой активности.

10.Проверить гипотезу о преобладании неактивных гильдий.

11.Рассчитать Paying Share и ARPPU для групп активности.

12.Исследовать гипотезу о связи платежного поведения создателей с активностью гильдий.

13.Подготовить рекомендации для дальнейшего анализа и принятия продуктовых решений.

Инструменты: Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Scikit-learn.

Моя работа:

1.Написал код для загрузки и предобработки данных (обработка пропусков, агрегация энергии по гильдиям, фильтрация по датам).

2.Подготовил признаки активности (количество добавленных/удаленных персонажей, уровень, миссии и т.д.) и масштабировал их с помощью StandardScaler.

3.Провел кластеризацию методом K-Means, определив оптимальное число кластеров с помощью метода локтя и метрики Silhouette.

4.Сформировал профили кластеров и выделил группы «Низкая», «Средняя» и «Высокая активность».

5.Объединил данные об активности с информацией о платежах (payers.csv), рассчитал метрики Paying Share и ARPPU для каждой группы.

6.Сформулировал логику проверки трех гипотез (включая анализ целесообразности повышения стоимости создания гильдии) и предусмотрел защиту от подмены реальных данных вымышленными.
